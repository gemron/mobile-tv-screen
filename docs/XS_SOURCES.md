# XS 订阅适配与验证

检查日期：2026-11-18；版本：1.3.0。配置来自 [XS 订阅](https://cyao2q.github.io/files/xs.json)，共有 66 个条目，更新前有 45 个未识别。

本版为这些条目接入原生处理器，包括 2 个桌面替代入口。**识别配置、读到列表、解析出媒体和实际播放是不同阶段**；本页没有把接入数量当作全站播放成功数量。域名、访问限制、账号权限、订阅密钥和站点结构仍可能变化。

不运行远端 JavaScript、Android 字节码或原生库。插件仅作为有界 ZIP／DEX 配置数据读取，并校验订阅声明的 MD5；每个条目自己的 `jar` 优先于订阅全局 `spider`。没有增加打包的 Android／Java 运行时。

## 验证范围

- `npm test` 包含合成 AppGet、App99、AppDrama 服务端：验证签名请求头、AES 封包、二进制 protobuf、目录／详情／媒体解析和取消边界，不依赖第三方密钥或用户账号。
- 新版安装包还检查媒体解码器、AAC／H.264 编码器、字幕渲染、精简依赖中的磁力组件初始化，以及独立运行、Range、封装和 FFprobe。
- 真实站点抽测不绕过人机验证、会员／付费权限、地区限制或私有下载协议。AppDrama 已实现协议处理，但本次握手失败仍是未通过项；不能据此承诺天堂、华谊、苹果可以播放。

## 发行包精简

所有顶层 npm 依赖均有现有功能使用，未直接卸载。发行时只保留实际使用的 HLS／MPEG-TS 浏览器构建，去除源码映射、类型声明、测试、示例、浏览器端 WebTorrent 重复构建和非 Windows x64 的预编译文件。运行时代码、Node.js、网盘／投屏／字幕／磁力依赖和许可证均保留。

媒体工具改用 [Gyan FFmpeg Essentials 8.1.2](https://www.gyan.dev/ffmpeg/builds/)，准备脚本固定版本及 SHA-256。FFmpeg 与 FFprobe 合计从约 402 MiB 减至约 194 MiB；发布前使用该版本完成媒体、音轨、字幕及安装包测试。此变更不降低原视频分辨率。
