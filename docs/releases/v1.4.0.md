# MobileTV 1.4.0

Windows 接收窗口现在使用内置的 Electron 播放器。关闭窗口后，接收服务继续在托盘运行；再次打开 MobileTV 可回到接收界面。

- 直接读取原有的订阅、账号、收藏与历史。Electron 使用独立的浏览器配置，窗口内保存的偏好可以重新设置。
- 修复拖动 MKV 进度条时缓冲颜色消失，以及方向键操作后进度条出现长焦点框的问题。
- 精简选集加载提示，保留转圈和状态文字。

Windows 10 / 11 x64 用户可选择 Setup 安装包，或完整解压便携 ZIP 后运行 MobileTV.exe。SHA256SUMS.txt 提供两种下载的校验值。
