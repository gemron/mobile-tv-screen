# MobileTV 1.2.3

修复兼容播放只显示几秒可播缓冲、部分影片无声以及高码率 MKV 内置字幕读取超时的问题，整理播放器、选集和片库的操作布局。

- **可播缓冲更准确**：按完整媒体片段的音视频时间计算“本机可播”，进度条区分已播放、播放器缓冲和本机已完成预读。拖动和换音轨排除旧请求，不再将缓存字节或流式封装已到达时长误当成可播秒数、影片总时长。
- **音轨与内置字幕**：读取真实语言、编码和声道，切换音轨保留进度；AC-3／DTS 等音频兼容为 AAC 立体声，复制原视频码流。带字幕索引的 MKV 直接读取字幕块、跳过音视频负载；MP4 等其他容器使用有界窗口提取。字幕读取支持加载提示、取消、失败重试及拖动后更新。
- **免费字幕搜索**：优先使用本机或订阅提供的 Assrt Token；没有 Token、Assrt 暂不可用或没有结果时尝试迅雷免费接口。保留片源字幕、本地文件、链接、ZIP 选择、延迟和字号调整。
- **夸克临时剧集清理**：默认在播完／换集后及空间不足时，将本软件转存的临时文件移入回收站；账号管理可调整或关闭。只处理记录中的精确文件编号，保护当前播放、正在保存、已改名或移走的文件，保留原有网盘文件，不清空回收站。容量不足清理成功后，仅重试已授权的本集一次。
- **播放操作**：新增按影片／剧集记忆的片头、片尾和自动跳过；修复鼠标点击倍速不生效。设置、字幕面板采用双栏半透明布局、细滚动条和响应式排布，账号管理收起可选手动凭据，长文件名选集不再横向撑出窗口。
- **片库与赛事**：片源和搜索合并，切换片源保留关键词；播放器工具栏更紧凑。赛事列表及详情显示源站提供的队标与队名，失效直播线路在起播前给出错误并保留换线入口。

## 验证与边界

通过协议、缓存、时间轴、网盘清理保护、音轨和字幕自动化测试，以及真实 Chrome／Edge 的字幕选择、跳转、倍速、片头片尾和片库操作回归；Windows 便携包和安装版另作独立启动、媒体处理及退出检查。

真实 4K MKV 样本读取不到 1 MiB、约 7 秒取得 36 条内置字幕；该结果只代表测试样本。流畅度、线路速度、字幕覆盖和网盘可用画质仍取决于源站、网络、文件索引、账号权限及设备。ASS 保留对白和时间，未完整还原特效排版；内置 PGS 等图像字幕需手动启用视频转码，可能增加 CPU 占用并影响 HDR。失效源站不能通过客户端保证恢复。

## 下载与升级

提供 Windows x64 安装版、便携 ZIP 和 `SHA256SUMS.txt`。便携版须完整解压，不要单独复制 EXE。升级前退出旧版托盘；账号、订阅、历史和收藏继续保存在 `%LOCALAPPDATA%\MobileTV\data`，发行包不含开发电脑的账号或历史数据。
