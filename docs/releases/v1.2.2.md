# MobileTV 1.2.2

修复夸克高码率原文件只有少量可播放数据、容易等待慢分段的问题，并加入字幕功能及新的应用图标和标题栏。

- **高分辨率缓冲**：4K 原文件缓存最多 512 MiB、前向窗口最多 384 MiB；2K 最多 256 MiB。按实际分辨率将并发扩展至 192／384，最多使用四条 HTTP/2 连接，保留原画、拖动优先及有界内存。
- **封装后预读**：额外准备最多 64 MiB 的可播放数据，约 1 秒的短片段，保留拖动后的音画时间轴。设置分别显示浏览器可播放秒数、原文件缓存与封装后缓存；浏览器只显示几秒不代表服务端没有备用数据。
- **字幕**：片源附带字幕、Assrt 搜索及文件选择、本地文件、链接、ZIP 内字幕、延迟和字号调整；按 S 打开。优先使用手动 Token，否则读取订阅 `assrt`；未提供时需要配置自己有权使用的 Token。
- **界面**：统一青绿渐变图标，16～256 像素多尺寸 ICO；深色原生标题栏显示当前影片，保留系统窗口操作和高对比度设置。

真实 3840×2160 HEVC 样本的持续取流从约 10 Mb/s 提升到约 27～29 Mb/s，封装后备用数据积累到约 64 MiB。Chrome／Edge 合成测试中，浏览器显示约 2.3 秒缓冲时，源站不可用 8 秒仍可连续播放；拖动与音画同步另行回归。测试结果代表样本，实际速度和流畅度取决于源站、网络、码率及设备。

支持 SRT／VTT／ASS／SSA 文本；ASS 保留对白和时间，不还原特效排版。RAR／7z、图像字幕及自动提取 MKV 内嵌字幕尚未实现。

提供 Windows x64 安装版、便携 ZIP 和 SHA256SUMS.txt。升级前退出旧版托盘，账号、订阅、历史和收藏保存在独立用户目录。
