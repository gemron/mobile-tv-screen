### 主要更新

- **多片源并发搜索与搜索历史**：全站搜索提升至 6 并发，默认按片源聚合首条匹配结果（每源前 1），可一键切换“全部”或按片源标签分开查看；支持保存最近搜索词、一键回搜与删除，播放历史与收藏支持实时搜索筛选。
- **片源验证适配与会话持久化**：统一识别 Cloudflare、网宿与常见中文 WAF 人机验证，秒级展示“打开验证页面”入口；验证完成后自动持久化 Cookie 与匹配的浏览器 User-Agent（重启软件后仍有效），并同步到适配器、通用 CMS/T4 站点与同源媒体播放请求；适配糯米移动端模板与 MacCMS v8/v10 播放解析。
- **播放交互与网盘直播**：视频画面单击暂停/播放、双击全屏（不误触暂停），点击弹层外部收起菜单不误暂停；夸克网盘分享需转存时自动确认单集转存并直接播放。
- **多音轨 MKV 与内嵌字幕修复**：自动识别 MKV 容器（含加密扩展/魔数/BT 磁力）并转封装为立体声 48 kHz AAC fMP4；支持 zlib 压缩内嵌字幕、TrackTimestampScale、视频单轨 Cues 扫描与 HTTP 200 非 Range 回退。
- **HLS 坏切片与失效播放列表保护**：代理层校验 `#EXTM3U` 拒绝改写过期 HTML 页面，拦截伪 HTTP 200 的 JSON/HTML 坏切片且不污染内存缓存，播放器在检测到连续残缺切片时自动提示换线。
