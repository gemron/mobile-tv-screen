# MobileTV 1.2.1

2026-11-16 · Windows 10 / 11 x64

本版补齐日常片库与直播操作，优化夸克原文件和高分辨率播放，并修复换集时的解析状态问题。

## 主要更新

- **片库更紧凑**：保存、命名和切换最多 30 个订阅；新增播放历史、剧集续播、影片和频道收藏。
- **直播更像电视**：频道编号、收藏台、上次观看、播放中频道表、数字选台与键盘上下台；赛事按日期、状态和开赛时间展示。
- **夸克原文件与缓冲**：保留原画，使用 HTTP/2 小分段并发读取；按实际分辨率和估算码率调整 32～256 MiB 有界内存缓存。MKV 可兼容封装，直接复制视频码流。
- **高分辨率与同步**：桌面优先使用已安装的 Chrome，回退 Edge；修复兼容封装拖动后声音提前。进度条显示真实缓冲区间，设置点击外部收起。
- **解析与换集**：加载动画、等待时间、取消、超时和重试；快速换集忽略旧结果。厂长支持无扩展名 Artplayer 媒体地址，避免将广告插件链接作为正片。
- **片源与搜索**：海绵授权、厂长媒体请求头及一直播的虎牙／斗鱼／B站取流更新；完整片名优先，支持演员匹配和逐步返回结果。
- **B站专用投屏（实验）**：专用设备发现、画质切换、DASH 音视频、弹幕、分集连播及本机官方网页登录。新安装默认关闭，可在设备设置中开启。

## 验证与边界

全套协议与功能测试、真实 Edge 片库回归通过。所反馈的厂长第 2 集实测为 1920×800、约 68 分钟正片，跳到 5 分钟后继续播放；快速换集、关闭取消、断开请求、解析截止及迟到结果均有回归覆盖。

片源可用性仍受上游、账号权限、网络和设备解码能力影响。易听与立播可能需要人工验证；AI剧、完整 Android 私有插件、EPG／回看、DRM 与苹果屏幕镜像尚不支持。B站 4K 等档位以平台实际授权为准。详见[兼容清单](https://github.com/gemron/mobile-tv-screen/blob/v1.2.1/docs/SOURCE_COMPATIBILITY.md)与[完整更新日志](https://github.com/gemron/mobile-tv-screen/blob/v1.2.1/CHANGELOG.md)。

## 下载与升级

- `MobileTV-1.2.1-Setup-x64.exe`：安装版，内置 Node.js 和 FFmpeg。
- `MobileTV-1.2.1-win-x64-*.zip`：便携版，完整解压后运行 `MobileTV.exe`。
- `SHA256SUMS.txt`：安装包和便携包校验值。

升级前请从托盘退出旧版，再安装或运行新版。订阅、账号、历史与收藏保留在 `%LOCALAPPDATA%\MobileTV\data`；发行包不包含开发电脑的账号、订阅或调试数据。
