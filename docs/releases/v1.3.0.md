# MobileTV 1.3.0

扩展 XS 订阅片源支持，修复拖动后的缓存复用、海报加载和返回列表状态，并精简 Windows 安装包。

- 新增原生 AppGet／AppQi／App99／AppDrama、独播、360、B站影视、网盘搜索、电台、DJ、戏曲和静态 XBPQ 规则处理；支持逐站 `jar` 与镜像配置。
- 修复原文件缓存淘汰和精确续传，拖动时保留已完成数据、取消旧预读，回退可以复用缓存；历史与前向缓存仍有内存上限。
- 返回列表保留分类、搜索、订阅、滚动位置和焦点；推荐片源弹窗固定标题和关闭入口。
- 修复百度转图／豆瓣转发海报，推荐页 120 张图片通过浏览器解码检查；地区访问限制与登录验证分开提示。
- FFmpeg／FFprobe 改用经过校验的 8.1.2 Essentials；发行包移除重复浏览器构建、源码映射、测试、示例和其他平台预编译文件，保留运行组件和许可证。

验证：完整自动测试、真实浏览器片库交互、本地加密接口模拟，以及 Windows 便携包／安装包独立运行验证。逐源结果见 [XS 兼容清单](../XS_SOURCES.md)。

**限制**：天堂／苹果本次握手返回 RSA 错误，华谊及部分站点连接失败；这些条目尚未通过真实播放验证。网盘需要自己的账号，会员、地区权限及专有下载协议继续受原服务限制。

本软件仅供学习、研究和非商业技术测试使用，禁止商业售卖；第三方组件遵循各自许可证。
