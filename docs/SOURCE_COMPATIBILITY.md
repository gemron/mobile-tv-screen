## 登录、上游变更与安全

在“网盘账号”中登录自己的夸克、UC、阿里或百度账号，或在“打开站点浏览器”完成源站验证；可以在“站点设置”更新接口地址和自己的 Cookie。API 摘要不会返回这些账号值。

网盘分享由相应平台决定可播放画质和访问权限。未实现绕过付费、验证码或 DRM。目录解析和账号交互已接入不表示所有平台都已通过真实账号测试。

Android 私有容器只用于按需读取互操作数据；不执行其中的 DEX/JNI，不在发行包里分发源站插件或反编译产物。drpy 脚本同样只提取声明的数据，各站请求逻辑由 Node.js 实现。
