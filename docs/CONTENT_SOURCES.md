# 电脑独立点播与直播

MobileTV 的影视与直播入口直接由电脑请求订阅、影片接口和媒体资源。手机可以关掉，不需要手机上的 OK影视、Android 运行环境、Java 或模拟器。投屏功能仍可独立使用。

## 当前兼容情况

| 来源 | 支持内容 | 边界 |
| --- | --- | --- |
| TVBox JSON / JSONC 订阅 | 站点、解析器、直播列表、配置仓 | 支持注释、尾逗号、Base64 及带 `**` 标记的图片封装 |
| type 0 | XML 采集接口 | 分类、分页、搜索、详情、剧集 |
| type 1 | JSON 采集接口 | 同上，保留接口已有查询参数 |
| type 4 | CatVod HTTP API | 分类、分页、搜索、详情、play 解析 |
| `csp_T4` / `csp_T4Guard` | FTY 扩展配置解码后访问采集接口 | 实现配置编码格式，不加载原插件 |
| `csp_Dm84` / `csp_Dm84Guard` | 动漫巴士分类、搜索、剧集、播放器接口 | 支持 iframe 与公开解析接口，未执行网页脚本 |
| `csp_Auete` / `csp_AueteGuard` | 奥特分类、搜索、剧集、媒体地址 | 支持播放器 URL 和 Base64 地址 |
| `csp_FirstAid` / `csp_FirstAidGuard` | 急救分类、搜索、教学视频 | 使用站点公开 HTML 和视频地址 |
| M3U / TXT / JSON | 频道分组、搜索、多线路、换台 | 支持 VLC UA / Referer、URL 后的请求头参数 |
| 其他 Android 私有插件 | 列出名称与未支持原因 | 尚未移植，不能直接运行 JAR / DEX / ARM 库 |
| drpy / 任意 JavaScript | 列出未支持原因 | 不在 Node 主进程执行第三方脚本 |

2026-11-15 验证用户提供的饭太硬配置时，共 49 个站点，5 个已适配。使用真实 Edge 实测：光影、奶酪、奥特、动漫巴士均解码出 1920×1080，急救为 1280×720，实际播放时间持续前进。这是所抽测视频的结果，不代表所有影片都是同一画质，也不保证源站之后始终可用。

该配置中的「综合」读取到 112 个频道、6 个分组；Kimentanm 读取到 120 个频道、4 个分组。列表成功不等于每个频道当前都能播放。指向 Android 本机 `127.0.0.1:9978/proxy` 的直播源会明确标为待适配，电脑不能直接复用手机本地服务。

同次验证还读取了虎牙、斗鱼、YY 频道列表，并通过真实 Edge 播放 Kimentanm 中的 CGTN 英语直播。频道数量和节目可用性会随源站实时变化。

## 使用方式

在顶部选择「影视」或「直播」，填入自己的订阅 URL。程序未内置、推荐或捆绑第三方内容源。订阅可使用中文域名，保存时按标准 URL 转成可请求的域名。

点播：选择站点 → 分类 / 搜索 → 详情 → 线路 → 剧集。默认直接播放，手动选择解析器时支持返回 JSON 的解析接口；网页嗅探型、需要完整浏览器环境或登录挑战的解析器尚不通用。没有得到媒体地址时显示具体错误，不用投屏回调伪装成独立播放。

直播：选择源 → 分组 / 搜索 → 频道。播放中的「换线」用于有多个地址的频道；上下台会循环切换。`N` 下一集 / 台，`P` 上一集 / 台，其他播放器快捷键保持有效。

配置保存在运行数据目录的 `library-config.json`。Windows 安装版默认是 `%LOCALAPPDATA%\MobileTV\data`。该文件可能含订阅令牌或请求头，不应上传到公开仓库。界面的兼容摘要不会返回 Cookie、Authorization 或原始插件扩展配置。

## 运行方式与缓存

- 订阅读取最大 8 MiB，超时和重定向均有上限；HTML 页面最大 4 MiB。
- 分类、搜索、详情与频道元数据缓存合计最多 16 MiB、32 项，按用途过期。
- 需要专用请求头的媒体使用服务端上下文 ID，媒体代理、HLS 子清单、分片和密钥均沿用同一上下文。
- 上下文最多 256 项，空闲 6 小时后失效；缓存按上下文隔离，避免不同请求头串用。
- HLS 点播沿用原播放器的 60–90 秒缓冲与 64 MiB 分片缓存；不将所有直播分片永久写入磁盘。
- 常规 HLS / MP4 不重编码。需要 FFmpeg 时默认视频码流复制；源站给多少清晰度就播放多少，不会把低清伪装成高清。
- 新的播放请求、配置切换和手机投屏会使旧解析失效，迟到的解析结果不能覆盖新会话。

## 添加适配器

通用接口与媒体解析在 `src/content/catalog.js`，原创 HTML 适配器在 `src/content/html-sites.js`。`describe()` 识别插件名称，`list()`、`detail()`、`resolve()` 分别实现列表、剧集和媒体解析。新增适配需要提供本地可重复的协议测试，确认分类、搜索、分页、详情、线路及实际媒体播放；仅成功解密扩展配置不能算完成站点适配。

当前实现只重现互操作所需的配置格式、请求参数和页面数据结构。仓库与发行包不分发第三方私有插件、还原后的 DEX 或反编译源码，不把整个 Android 业务执行环境搬进 Node.js。

## 本地验证

```powershell
npm test
npm run test:library:browser
```

浏览器测试创建临时数据目录和独立 Edge 配置，使用本地合成媒体验证播放、专用 UA / Referer、自动连播与换台。不会修改日常使用的订阅。

需要对用户给定的第三方源作实时验证时，可显式联网运行：

```powershell
npm run test:library:browser -- --real-source
# 只验证其中一个站点
npm run test:library:browser -- --real-source --site=Dm84
# 使用同一订阅中的 CGTN 英语频道验证真实直播
npm run test:library:browser -- --real-live
```

这项可选测试不进入默认 CI，因为源站可用性、域名变化和接口风控不由本项目控制。实际测试分辨率和前进时间会打印到终端。
